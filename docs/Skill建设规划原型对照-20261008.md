# Skill 建设规划与原型对照

日期：2026-10-08。范围：将产品文档的 Skill 建设规划体现到 axn-demo 现有原型，不建设生产模型或平台服务。

## 依据与缺口

- `../doc-emergency-anneng/output/指导/四类智能体总体产品设计.md`：四业务智能体专属 Skill 清单。
- `../doc-emergency-anneng/output/指导/四类智能体总体产品设计_v4.md`：来源、时间、版本、人工责任门和写操作约束。
- `../doc-emergency-anneng/output/出稿/8.4.6.7. Skill与运行规范.md`：调用契约、分层、权限、热插拔、降级和审计；其中数量、时限等仍须与最终设计和合同核对。
- `../doc-emergency-anneng/src/data/agentSkills.js` 与 `AgentSkillPanel.vue`：六智能体分工、输入输出及边界的参考设计。

修改前，React 侧栏隐藏了智能体目录，深链页面仅显示五智能体的简短标签，无法打开输入输出详情。Vue 的旧 Skill 面板仍保存在源码，但当前 `browserAssist` 路由指向 `AnnengChatStart.vue`，本次访问的方案入口也没有显示该面板。因此参考其能力与边界设计，不将旧组件等同于当前可见体验。

## 规划映射

| 建设要求 | 原型入口与行为 | 当前边界 |
| --- | --- | --- |
| 四业务智能体与两共用支撑 | 侧栏“智能体与 Skill”，六分组可切换 | 43项是此次目录整理数量，不是合同承诺或生产注册数量 |
| 态势专属能力 | 多源汇聚、抽取去重、时序推演、图谱、CV、资源叠加、报告、推送、等级规则 | 有对应 mock 流程的标“本地模拟”；其余“待建设” |
| 资源专属能力 | 物联、同步、校正、台账、匹配、编组、路径、跨平台、消耗回写 | 实时台账、优化、路线和正式回写未接入 |
| 方案专属能力 | RAG、案例、规则、红线、多维评估、版本、编成、导出、动态修订 | 本地材料导出不表示正式签发；专业服务待建设 |
| 评估专属能力 | 计划、执行聚合、偏差、指标、完整度、归因、知识抽取、发布、迭代任务 | 当前结果示例不等于完成生产计算或知识发布 |
| 共用支撑 | 上下文、呈现、原系统读取核验、模板、编排、引用、导出 | 原系统浏览器服务与生产接口仍待联调 |
| Skill 契约 | 点击名称或“查看详情”，展示输入输出、草案标识和版本、来源、权限、前置与降级 | v0.1.0为展示草案，无生产Schema或版本注册 |
| 运行治理 | “共用运行规范”展示契约、确认、热插拔、Trace、弱网 | 明确统一平台与业务智能体的协同边界 |
| 建设路径 | “建设与验收路径”展示契约确认、联调、闭环验证、试运行 | 依据文档整理的顺序，不声明阶段已完成 |
| 任务内可追溯 | 任务卡“查看本次执行与能力分工”读取同一任务的步骤、尝试ID、来源和错误 | 是本地任务记录与规划对照，绝不冒充逐Skill的生产调用日志 |

## 操作与验证

1. 进入目录：侧栏入口与深链可访问，六类分组正常。
2. 查找能力：搜索“红线”只显示红线拦截；方案分组筛选“本地模拟”只显示方案导出；详情显示待建设和人工责任门。
3. 查看运行规范：五类共性约束及平台边界可见。
4. 发起态势任务：生成灾情摘要后打开执行对照，实际步骤、输入输出和来源来自任务记录，未记录内容明确保留为空缺说明。
5. 失败测试：失败步骤保留错误和来源；待建设RAG不会变成执行成功。重试使用当前attempt标识。

- `pnpm typecheck`、`pnpm lint`通过。
- 生产构建通过。
- Node 24运行三个定向测试文件，共22项通过；默认Node 20无法运行当前jsdom/undici测试环境。
- 浏览器用内置浏览器验证，无CLI Playwright或全量e2e；已有导航spec同步新的可见入口与唯一选择器，但未运行该spec。
- 控制台仅观察到既有文书Drawer的width弃用提示，未观察到新增页面运行异常。
- 截图可支持桌面布局检查，不能证明完整无障碍合规；新增按钮、筛选和搜索保留语义标签。
- 尝试390px视口设置后浏览器仍返回1280×720，窄屏验证未完成；响应式CSS已有配置，不将其记为已验证。
